# Контракт модуля

Каждый инструмент — модуль. Встроенные модули лежат в `src/modules/<id>/`.
Внешние (только в `dev`-сборке) — один HTML-файл, работающий в изолированном iframe.

## Описание модуля (manifest)
```js
export default {
  id: 'metronome',              // латиница, уникально
  name: { ru: 'Метроном', uz: 'Metronom', en: 'Metronome' },
  i18n: { ru, uz, en },         // словари модуля (импорт из ./i18n/*.json)
  icon: '<svg …/>',             // монохромный SVG, цвет через currentColor
  color: '#FF9500',             // цвет карточки и значка
  sizes: ['full', 'half', 'quarter', 'strip'], // какие размеры окна поддерживает
  group: 'rhythm',              // необязательно: объединение в сессии (метроном + тюнер)
  status: (ctx) => '120 bpm · 4/4', // строка для карточки в «Инструментах»
  mount(host, ctx, size) {},    // нарисовать модуль в host (DOM-элемент) в размере size, подписаться на события
  resize(size) {},              // окно поменяло размер: 'full' | 'half' | 'quarter' | 'strip'
  unmount() {},                 // снять подписки, остановить звук
  settings: (ctx) => [],        // необязательно: описание настроек для общего экрана
};
```

## Что ядро даёт модулю (`ctx`)
- `ctx.t(key, vars)` — перевод строк модуля (`src/modules/<id>/i18n/{ru,uz,en}.json`), `{name}` → `vars.name`.
  `ctx.tn(key, n)` — строка с числом и склонением (в словаре — массив форм). `ctx.num(n, digits)` — число по правилам языка.
- `ctx.store` — настройки модуля на устройстве, пространство имён `device[id]` (`practice.v1.tools`):
  `get(k, def)`, `set(k, v)`, `all()` (сам объект — можно менять и вызвать `save()`), `subscribe(fn)`.
- `ctx.audio` — общий звуковой движок: `bus('piano' | 'metro' | 'drone' | 'theory' | 'media')`,
  `playNote(midi, opts)`, `playChord(midis, opts)`, `playSeq(midis, opts)`, `refTone(midi)`, `now()`, `mf(midi)`;
  общие инструменты `metro`, `drone`, `synth`, `mixer`. Громкость шины управляется микшером ядра.
- `ctx.mic.request()` — микрофон по явному разрешению пользователя; поток только для анализа.
  Возвращает `{ read(), sampleRate, stop() }`, ошибка — с `reason: 'denied' | 'unavailable'`.
- `ctx.presets(kind)` — свои пресеты звука (`'piano'`, `'drone'`) в общих данных (попадают в резервную копию):
  `list()`, `get(id)`, `add(name, data)` → id, `rename(id, name)`, `remove(id)`. Ряд и менеджер — `src/ui/presets.js`.
- `ctx.shared` — общие значения между модулями на время работы: `get(k)`, `set(k, v)`, `subscribe(fn)`.
  Например, `highlight: { pcs: Set, root, label }` — подсветка ступеней на пианино из «Теории».
- `ctx.openTool(id)` — открыть другой инструмент (из «Теории» — пианино с подсветкой гаммы).
- `ctx.peek(id)` — настройки другого модуля, только чтение (копия). Например, строй из тюнера для грифа.
- `ctx.audio.drone.tonic(pc)` — дрон на ноте (сменить тонику и зазвучать).
- Общая музыкальная основа без DOM — `src/music/` (`notes.js`, `theory.js`, `tuning.js`); модули импортируют её напрямую.
  Общая клавиатура — `src/ui/keyboard.js`.
- `ctx.pomodoro` — таймер помодоро ядра (идёт и при закрытом окне, ставит сессию на паузу в перерыв):
  `phase`, `running`, `done`, `rem()`, `total()`, `toggle()`, `reset()`, `next(manual)`, `release()`, `subscribe(fn)`.
- `ctx.files` — файлы пользователя на устройстве (IndexedDB): `ready` (промис), `noDb`, `list('audio'|'tab')`, `get(id)`,
  `add(rec)`, `save(rec)`, `remove(id)`, `subscribe(fn)`. Привязка к песням — `fileSongs`, `inSong`, `linkSong` из `src/core/files.js`.
- `ctx.confirmUpload()` — перед выбором файла: один раз показывает предупреждение о правах на файлы, промис `true/false`.
- `ctx.songs()` — список песен `{ id, title }`, только чтение.
- `ctx.session` — текущая сессия (песня, если есть), только чтение.
- `ctx.song()` — песня текущей сессии `{ id, title, notes, tr }` (копия) или `null`;
  `ctx.updateSong({ notes?, tr? })` — правка текста с аккордами и транспонирования (−11…+11), другие поля песни модулю недоступны.
- `ctx.data()` / `ctx.saveData()` — данные модуля в общем состоянии (`state.settings[id]`, попадают в резервную копию),
  например статистика ответов тренажёра слуха. Время в модуле ядро считает само.
- `ctx.ui` — общие элементы: `toast`, `sheet` (нижняя шторка), `confirm`, `icons`, токены темы (CSS-переменные).
- `ctx.pro`/флаги — не используются в публичной версии (приложение бесплатное).

## Правила
- Модуль не лезет в DOM за пределами `host` и не трогает данные ядра напрямую.
- Каждый поддерживаемый размер окна должен выглядеть аккуратно (принцип: в маленьком окне —
  только самое нужное, как у метронома и пэдов).
- Цвета — только из CSS-переменных темы; поддержка светлой/тёмной и акцента обязательна.
- Строки — только через `ctx.t`. Подписи `aria-label` для всех кнопок.
- `unmount` обязан остановить звук и таймеры.

## Внешние модули (только `dev`)
- Один HTML-файл; запускается в `<iframe sandbox="allow-scripts">`.
- Общение только через `postMessage` с узким API: `playNote`, `log`, `store.get/set`, `toast`, `size`.
- Без доступа к песням, сессиям, файлам. Микрофон — только по отдельному разрешению.
- Ставится из файла на устройство; общего каталога нет.
