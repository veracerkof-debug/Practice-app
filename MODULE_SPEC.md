# Контракт модуля

Каждый инструмент — модуль. Встроенные модули лежат в `src/modules/<id>/`.
Внешние (только в `dev`-сборке) — один HTML-файл, работающий в изолированном iframe.

## Где лежат модули
- `src/modules/<id>/index.js` — встроенные (для всех), `src/modules-local/<id>/index.js` — личные (не попадают в репозиторий).
- Ядро подключает их само (`src/modules/index.js`): новая папка — новый инструмент, правок в ядре не нужно.
  Описание без обязательных полей (`id`, `name`, `icon`, `sizes`, `mount`, `resize`, `unmount`) не подключается —
  в «Профиль → Модули и функции» появляется строка с ошибкой, приложение работает дальше.
- Любой модуль включается и выключается в «Модулях и функциях» (`settings.off[id]`), данные при этом сохраняются.
- Шаблон с инструкцией — `docs/module-template/`.

## Описание модуля (manifest)
```js
export default {
  id: 'metronome',              // латиница, уникально
  order: 10,                    // необязательно: место среди инструментов (встроенные — 10…90, свои — по умолчанию 1000)
  name: { ru: 'Метроном', uz: 'Metronom', en: 'Metronome' },
  i18n: { ru, uz, en },         // словари модуля (импорт из ./i18n/*.json); ключ about — описание в «Модулях и функциях»
  icon: '<svg …/>',             // монохромный SVG, цвет через currentColor
  color: '#FF9500',             // цвет карточки и значка
  sizes: ['full', 'half', 'quarter', 'strip'], // какие размеры окна поддерживает
  group: 'rhythm',              // необязательно: одно окно сессии на группу с переключателем (метроном + тюнер)
  groupSizes: ['full', 'half'], // необязательно: в окне группы меньшего размера показывается другой модуль группы
  session: false,               // необязательно: не ставится в окна сессии (тренажёр слуха, помодоро)
  inner: true,                  // необязательно: нет в «Инструментах», быстром доступе и панели сессии — открывается из другого модуля (`ctx.openTool`)
  stats: false,                 // необязательно: время в модуле не идёт в статистику (спектр и шумомер)
  immersive: true,              // необязательно: в отдельном окне — на весь экран, без шапки; «назад» плавает поверх (глайдер)
  rotate: (ctx) => null,        // необязательно: 'r' | 'l' — повернуть весь экран сессии, пока модуль в окне
  multitouch: true,             // необязательно: играют несколькими пальцами — пока открыт, системный снимок экрана тремя пальцами
                                //   не срабатывает (на Android это выключает и запись экрана — только где правда нужно)
  record: false,                // необязательно: без кнопки записи в окне (по умолчанию запись есть у всех — звук приложения)
  recordVideo(host) {},         // необязательно: запись с видео — { stream (MediaStream с видео), stop() } или null (терменвокс)
  pure: true,                   // необязательно: в отдельном окне — полный экран, только рабочая поверхность (src/core/pure.js)
  onPure() {},                  // необязательно: полный экран включили или выключили — пересчитать раскладку
  midiIn(e) {},                 // необязательно: модуль понимает MIDI — играет событие (src/music/midi.js: on, mv, off, ped);
                                //   так звучат MIDI-клавиатура и воспроизведение записи; в записи появляется формат «MIDI»
  midiStop() {},                // необязательно (вместе с midiIn): отпустить всё, что зазвучало по MIDI
  status: (ctx) => '120 bpm · 4/4', // строка для карточки в «Инструментах»
  mount(host, ctx, size) {},    // нарисовать модуль в host (DOM-элемент) в размере size, подписаться на события
  resize(size) {},              // окно поменяло размер: 'full' | 'half' | 'quarter' | 'strip'
  unmount() {},                 // снять подписки, остановить звук
  settings: (ctx) => [],        // необязательно: описание настроек для общего экрана
};
```

## Что ядро даёт модулю (`ctx`)
- `ctx.t(key, vars)` — перевод строк модуля (`src/modules/<id>/i18n/{ru,uz,en}.json`), `{name}` → `vars.name`.
  `ctx.tn(key, n)` — строка с числом и склонением (в словаре — массив форм). `ctx.num(n, digits)` — число по правилам языка.
- `ctx.store` — настройки модуля на устройстве, пространство имён `device[id]` (`practice.v1.tools`):
  `get(k, def)`, `set(k, v)`, `all()` (сам объект — можно менять и вызвать `save()`), `subscribe(fn)`.
- `ctx.audio` — общий звуковой движок: `bus('piano' | 'glider' | 'metro' | 'drone' | 'theory' | 'media')`,
  `playNote(midi, opts)`, `playChord(midis, opts)`, `playSeq(midis, opts)`, `refTone(midi)`, `now()`, `mf(midi)`, `pianoPatch()` (текущий звук пианино — сыграть им своим голосом, как глайдер);
  общие инструменты `metro`, `drone`, `synth`, `mixer`. Громкость шины управляется микшером ядра.
- `ctx.mic.request()` — микрофон по явному разрешению пользователя; поток только для анализа.
  Возвращает `{ read(), sampleRate, stop() }`, ошибка — с `reason: 'denied' | 'unavailable'`.
- `ctx.presets(kind)` — свои пресеты звука (`'piano'`, `'drone'`) в общих данных (попадают в резервную копию):
  `list()`, `get(id)`, `add(name, data)` → id, `rename(id, name)`, `remove(id)`. Ряд и менеджер — `src/ui/presets.js`.
- `ctx.shared` — общие значения между модулями на время работы: `get(k)`, `set(k, v)`, `subscribe(fn)`.
  Например, `highlight: { pcs: Set, root, label }` — подсветка ступеней на пианино из «Теории».
- `ctx.openTool(id)` — открыть другой инструмент (из «Теории» — пианино с подсветкой гаммы).
- `ctx.peek(id)` — настройки другого модуля, только чтение (копия). Например, строй из тюнера для грифа.
- `ctx.audio.drone.tonic(pc)` — дрон на ноте (сменить тонику и зазвучать).
- `ctx.midi` — MIDI: `ev(e)` — событие своей игры (в запись, если идёт MIDI-запись этого модуля; иначе ничего),
  `play(rec)` — открыть инструмент записи и проиграть её, `share(rec)` — отправить `.mid`, `tool(id)` — название, значок
  и цвет инструмента. События — те же, что получает `midiIn` (у голоса свой `id`, высота `m` может быть дробной).
- `ctx.pulse` — сигналы без звука (вспышка экрана, фонарик, вибрация): `info()` — что есть на устройстве.
- `ctx.league()` — лига музыканта `{ hours, gem }`; `ctx.bible` — чтение Библии (церковный режим, `src/core/reading.js`).
- `ctx.mono` — вид «Минимал» (у инструментов с выбором вида он закреплён); `ctx.epigraph()` — стих-эпиграф.
- `ctx.log(msg)` / `ctx.logErr(e)` — технический журнал (`src/core/log.js`): только события, без названий и личного.
- Общая музыкальная основа без DOM — `src/music/` (`notes.js`, `theory.js`, `tuning.js`); модули импортируют её напрямую.
  Общая клавиатура — `src/ui/keyboard.js`.
- `ctx.pomodoro` — таймер помодоро ядра (идёт и при закрытом окне, ставит сессию на паузу в перерыв):
  `phase`, `running`, `done`, `rem()`, `total()`, `toggle()`, `reset()`, `next(manual)`, `release()`, `subscribe(fn)`.
- `ctx.stopwatch` — секундомер ядра (второй режим «Помодоро»; идёт при закрытом окне): `running`, `elapsed()`, `active()`,
  `toggle()`, `reset()`, `subscribe(fn)`, `credit()` — сколько секунд попадёт в статистику, `commit({ tag, note })` — записать
  как свободную практику (уже учтённое сессией или инструментами время не засчитывается дважды), `tags()` — метки практики.
- `ctx.files` — файлы пользователя на устройстве (IndexedDB): `ready` (промис), `noDb`, `list('audio'|'tab'|'midi'|'bible')`, `get(id)`,
  `add(rec)`, `save(rec)`, `remove(id)`, `subscribe(fn)`. Привязка к песням — `fileSongs`, `inSong`, `linkSong` из `src/core/files.js`.
- `ctx.confirmUpload()` — перед выбором файла: один раз показывает предупреждение о правах на файлы, промис `true/false`.
- `ctx.songs()` — список песен `{ id, title }`, только чтение.
- `ctx.session` — текущая сессия (песня, если есть), только чтение.
- `ctx.song()` — песня текущей сессии `{ id, title, notes, tr }` (копия) или `null`;
  `ctx.updateSong({ notes?, tr? })` — правка текста с аккордами и транспонирования (−11…+11), другие поля песни модулю недоступны.
- `ctx.data()` / `ctx.saveData()` — данные модуля в общем состоянии (`state.settings[id]`, попадают в резервную копию),
  например статистика ответов тренажёра слуха. Время в модуле ядро считает само.
- `ctx.openMixer()` — открыть шторку микшера (громкость и эффекты шин).
- `ctx.fxPanel({ get, set })` — общая панель эффектов (эквалайзер, сжатие, драйв, тремоло, задержка, хор, реверберация; `src/ui/fxpanel.js`):
  `html()` — разметка в шторку, `bind(el, api)` — после открытия (возвращает `{ mount }` — звать после `api.update()`). Звук — `createFxChain` из `src/audio/fx.js`.
- `ctx.ui` — общие элементы: `toast`, `sheet` (нижняя шторка), `confirm`, `icons`, токены темы (CSS-переменные).
- `ctx.pro`/флаги — не используются в публичной версии (приложение бесплатное).

## Правила
- **Пространство работает на функцию** (основной принцип приложения, см. `CLAUDE.md`): рабочая поверхность
  занимает всё окно; названия и украшения, не помогающие играть, — не нужны; управление — одной узкой полосой
  в краю; показания поверх поверхности не перехватывают касаний (`pointer-events: none`).
- Модуль не лезет в DOM за пределами `host` и не трогает данные ядра напрямую.
- Каждый поддерживаемый размер окна должен выглядеть аккуратно (принцип: в маленьком окне —
  только самое нужное, как у метронома и пэдов).
- Цвета — только из CSS-переменных темы; поддержка светлой/тёмной и акцента обязательна.
- Строки — только через `ctx.t`. Подписи `aria-label` для всех кнопок.
- `unmount` обязан остановить таймеры и звук. Исключение — сессия (`ctx.session` не пуст): окно могут перестроить
  или свернуть, звук (метроном, дрон, табы, медиатека) продолжает играть.

## Внешние модули (только `dev`)
- Один HTML-файл; запускается в `<iframe sandbox="allow-scripts">`.
- Общение только через `postMessage` с узким API: `playNote`, `log`, `store.get/set`, `toast`, `size`.
- Без доступа к песням, сессиям, файлам. Микрофон — только по отдельному разрешению.
- Ставится из файла на устройство; общего каталога нет.
