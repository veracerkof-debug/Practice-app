## Открыто — из обзора открытых проектов (см. DECISIONS, 2026-10)
- Идея, не план (автор 21.10: «больше игрушка, чем рабочий инструмент», сомневается): телефон как MIDI-клавиатура по Wi-Fi
  для другого телефона или Мелете на Windows — только MIDI и пресеты, не звук. Техника, если когда-нибудь: UDP (не TCP),
  пакет = номер + время + байты с повтором последних трёх событий; на Android — плагин с сокетом и `WIFI_MODE_FULL_LOW_LATENCY`,
  на Windows — `UdpSocket` в Rust; пресеты и ручки — отдельным надёжным каналом; сопряжение — QR (шаг 2 плана выше);
  RTP-MIDI (RFC 6295) вторым слоем для чужих DAW. Ожидаемая задержка 2–8 мс сети + буфер приёмника, всплески до 100 мс
  в занятом Wi-Fi; гостевые сети с изоляцией устройств не подходят. Виртуальный MIDI-вход в ядре уже есть (`midiIn`/`midiStop`).
- Репетиция группы по Wi-Fi по образцу GrooveForge: каждый телефон пишет свою партию под общий клик, задержка
  меряется чирпом, склейка в студии без хоста. Самая ценная из новых функций, большая работа.
- Аккорды и доли по записи (Chordino/NNLS или своя хрома + доли) в медиатеке: аккорды над волной, петля по долям.
- Тренажёр ритма с микрофона по образцу DrumCoach: удары и хлопки, ровность, нотный стан.
- Вокальный тренажёр по образцу Pitchtrain: диапазон, удержание ноты, дрейф, дневник голоса.
- Табы: выпрямление фото нот и Bluetooth-педаль (Notenkladde); петли по сетке долей и цепочки повторов (Rubber Ring).
- ✅ Модели для плеера медиатеки встроены (21.10): тональность, доли и темп, аккорды — в фоне и в плеере. Хвост: на Android разбор идёт в WebAssembly одним потоком (≈ время записи на телефоне); при жалобах на скорость — нативный ONNX Runtime для этих трёх моделей по образцу плагина `Stems`. Исходный обзор:
  S-KEY от Deezer — тональность по записи, 0,33 МБ, весь разбор внутри графа (точнее нашего профиля хромы); Beat This! (CPJKU) —
  доли и сильные доли, малая модель 10 МБ (темп точнее, сетка долей для петель и метронома по записи, такты в студии);
  ChordMini ChordNet 2E1D — аккорды по записи, 170 видов, 17 МБ (вход — лог-CQT, 10,8 кадров/с; аккорды над волной плеера,
  в текст песни). Не подходят: BTC (веса CC BY-NC), madmom (модели CC BY-NC), essentia.js (AGPL — совместимо, но тяжёлый WASM, выигрыша над S-KEY/Beat This нет).
- Android: изоляция COOP/COEP (свой локальный сервер Capacitor) — тогда дорожки на Windows и в dev считают в несколько потоков (Android уже нативный).

## Отложено до каникул (автор, 2026-10-21): Holyrics → Melete → Notion → Telegram в Windows-версии
По образцу VeraBot (бот автора на Python: Holyrics → Notion → Telegram, идемпотентно по хэшам, мастер настройки, архив
пропавших песен). У нас: запросы к Holyrics нативно из Rust (в окне их режет CSP — потому «не получилось» на компьютере),
слой обогащения — своя библиотека песен **и Notion тоже** (автор хочет Notion: тональность, теги, аккорды ступенями
правит команда там), публикация в тему супергруппы Telegram через бота; настройка в приложении (церковный режим,
«Команда»): адрес и токен Holyrics, токен Notion и id базы, токен бота и команда в теме группы; кнопка «Синхронизировать»
и переключатель «автоматически, раз в N минут»; хэши текста и id сообщений/страниц в хранилище, пропавшие — в архив;
токены не в резервную копию. Объём 3–4 дня с тестами на поддельных серверах. Начинать, когда автор сядет за компьютер
проверять (каникулы); до этого — ядро приложения.

- **Экран занятия «как Forest» (ревизия 22.10, не делал)**: через полминуты без касаний окно сессии затемняется до тихого вида — крупный таймер, тик метронома, ноты, камень растёт; касание возвращает всё. Приложение награждает за то, что к нему не прикасаются (принцип 4). См. `docs/review-defaults-2026-10-22.md`.

- **Ансамбль — что видел у других и не взял (23.10)**: выравнивание по самой музыке без сигнала (как синхронизация
  камер по звуку в видеоредакторах) — запасной путь, когда сигнал не услышан (сейчас — по часам); общий щелчок
  метронома в наушники всем (как Ableton Link — темп и доля по сети) — для записи под клик; телефон-хост (свой сервер
  в Android) — репетиции без компьютера; поправка на расстояние до динамика (≈ 3 мс на метр) — ручной сдвиг дорожки
  в студии ±1 мс; запись самого компьютера (его микрофон или карта) как ещё одной дорожки.
