## 1. ✅ Звук для поклонения (worship ambient) — терменвокс, синтезатор, пэды

Сделано: пэды и «Шиммер» в терменвоксе (по умолчанию, простой режим), набор для поклонения в синтезаторе.
Дальше по желанию: «Air» (шумовая подложка), длинная реверберация отдельно для пэдов.

**Что хочет автор.** Надёжный, настраиваемый набор звуков для эмбиента в поклонении: пэды, которыми управляют руками
в терменвоксе, и такой же набор в синтезаторе. По умолчанию — эти звуки, футуристические — оставить как вариант.
Ориентир по характеру — то, как звучат пэды и клавиши у команд вроде Bethel Music (звуки не копируются и не называются
их именами — только свой синтез в похожем духе).

**Что это за звук (свой синтез):**
- «Shimmer»-пэд: пилы/треугольники с хорусом, очень медленная атака (1–3 с), длинный релиз, реверберация 6–10 с,
  октава вверх в хвосте (shimmer — отражения реверберации с транспонированием на октаву, можно приближённо:
  второй хвост ревера через квинту/октаву с тихим уровнем).
- «Swell»: громкость и фильтр медленно открываются при удержании (атака по фильтру, а не только по громкости).
- «Warm keys»: мягкое электропиано/пиано с длинным сустейном и ревером — для поддержки.
- «Air»: шумовая подложка (розовый шум через полосовой фильтр по нотам аккорда), очень тихо.
- Тоника и квинта (дрон) + аккорд — как в модуле пэдов; набор тональностей и «смена аккорда без щелчка» (кроссфейд 1–2 с).

**Где:**
- `src/audio/padvoice.js` / `drone.js` — уже есть пэды, которые нравятся автору: взять их набор как основу
  и вынести в общий движок, чтобы им пользовались терменвокс (голос высоты = нота пэда, вторая рука = громкость/фильтр/
  шиммер) и синтезатор (пресеты «Поклонение»: Shimmer, Swell, Warm keys, Air).
- `src/audio/synth.js` — пресеты и поле `shimmer`/`swell`; `PATCH_EXTRA` для своих пресетов.
- Терменвокс: **режим по умолчанию — простой**: одна рука — высота (нота пэда с привязкой «ноты» к тональности),
  вторая — только громкость (раскрытая ладонь/кулак) и, по желанию, яркость. Остальные жесты — в разделе «Эффекты»,
  выключены по умолчанию. Звук по умолчанию — «Shimmer»-пэд в тональности; футуристические — в списке звуков.

**Проверка:** рендер нот OfflineAudioContext (уровень, отсутствие щелчков при смене аккорда), прослушивание автором.

## 3. Команды: отправка песен и списков

Melete — не только для одного человека, но и для команды (репетиции, служения).

**Что отправлять:** песню целиком — название, исполнитель, BPM, тональность (и транспонирование), текст с аккордами,
табулатуры и ноты (файлы), заметки; список песен (сет-лист репетиции) с порядком и тональностями.

**Как (без серверов и без сбора данных — правило 5):**
- Файл `.melete` (zip: JSON + файлы) → «Поделиться» (Telegram, WhatsApp, почта). Открытие такого файла в Melete →
  экран «Импорт»: что добавить, что заменить, конфликты по названию.
- Для коротких списков без файлов — ссылка/QR с данными (сжатый JSON в фрагменте ссылки), открывается в приложении.
- Связь с календарём: событие «Репетиция» с сет-листом → отправить всё одним файлом.
- Формат описать в `docs/` (версия формата, обратная совместимость), тесты на экспорт/импорт туда и обратно.

## 5. Маскот и цитаты (цитаты — готовы, `src/core/quotes.js`)

текстовый «голос» (место на главной «Минимала» уже есть: `mvoice`), потом — образ (нужны эскизы от автора;
вопрос — в `DECISIONS.md`).

**Цитаты — набор `src/core/quotes.js` (ru/uz/en), категории:**

   он будет стоять пред царями»), 1 Пар 15:22 (Хенания — «был сведущ»), 1 Пар 25:7 (288 певцов, «обученных пению
   Господу, все искусные»), 2 Тим 2:15, Пс 150, 1 Кор 14:40, Притч 13:4. Текст — Синодальный перевод (как в модуле
   Библии), ссылка на стих.

   **Только проверенные факты с источником** (книги, интервью): многие ходячие истории (например, о часах практики
   Хендрикса) преувеличены. В файле у каждой цитаты — поле источника; без источника — не добавлять.
