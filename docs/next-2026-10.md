## Сделано

   в синтезаторе. Свой синтез в духе эмбиента команд поклонения, без чужих звуков и названий.
2. ✅ **Уведомления** — `src/core/reminders.js`: расписание по дням недели, характер маскота, тихие часы,
   проверка кнопкой; точные напоминания — по разрешению «Будильники и напоминания».
3. ✅ **Команды** — файл `.melete` (`src/core/share.js`, формат — `docs/share-format.md`): песни, табы и ноты,
   записи по выбору, сет-лист из события календаря; приём кнопкой в «Песнях» и открытием файла.
4. ✅ **Помодоро в сессии** — шторка больше не сжимается.
5. ✅ **Маскот и цитаты** — Мелетий / Мелета / без маскота: одна фраза дня на главной, напоминания, тамагочи на занятии;
   наборы слов — `src/core/quotes.js` (Писание — Синодальный перевод; истории музыкантов — только с источником).

## Открыто
- Уведомления: проверить на устройстве после перезагрузки телефона и в режиме экономии батареи.
- Команды: ссылка или QR для коротких списков (сжатый JSON в ссылке) — по желанию.
- Маскот: новые эскизы образа — от автора (`docs/mascot/`).
- **Для iPhone — веб-приложение и/или мини-приложение в Telegram** (вопрос автора, отложено). Предложение: сначала PWA
  (manifest + service worker, ставится через Safari «На экран „Домой“»), бот выдаёт ссылку или открывает ту же сборку
  как мини-приложение. Не работает на iOS: папка Melete, напоминания, иконка, шторка/плавающая кнопка/всплывающее окно,
  MIDI (нет Web MIDI), Holyrics; звук молчит при беззвучном режиме и в свёрнутом Telegram. Риски: хранилище встроенного
  браузера Telegram может очищаться (нужны копии), Telegram видит открытия, скрипт telegram.org против правила «без CDN».
  Решить: только PWA, PWA + бот или только Telegram.
- Напоминания на Honor X9d не приходят: добавлены «Автозапуск» и строка «Ближайшее напоминание» — проверить на устройстве.
