# Шаблон модуля

Модуль — отдельный инструмент приложения (как метроном или тюнер). Ядро подключает модули само:
любая папка с `index.js` в `src/modules/` (встроенные) и `src/modules-local/` (личные) становится инструментом.

## Свой модуль для себя
1. Скопируй эту папку в `src/modules-local/<id>/` (папка `src/modules-local` не попадает в репозиторий).
2. Поменяй в `index.js` поле `id` (латиница, уникально) и название в `i18n/*.json`.
3. Запусти `npm run dev` — модуль появится во «Инструментах», его можно поставить в окно сессии
   и выключить в «Профиль → Модули и функции».
4. Для телефона — `npm run build` и сборка Android (этап 3).

## Встроенный модуль (для всех)
То же, но папка — `src/modules/<id>/`, плюс строка в `LICENSES.md`, если модуль тянет новую зависимость.

## Что обязательно
`id`, `name`, `icon`, `sizes`, `mount`, `resize`, `unmount` — иначе модуль не подключится, а в «Модулях и функциях»
появится строка с ошибкой. Остальное (`order`, `color`, `group`, `status`, `session`…) — по желанию.
Полный контракт и всё, что даёт ядро через `ctx`, — в `MODULE_SPEC.md`.

## Правила
- Строки — только через `ctx.t` (ru, uz, en), подписи `aria-label` у кнопок.
- Модуль не лезет в DOM за пределами своего `host` и не трогает данные ядра напрямую.
- Все размеры окна (`full`, `half`, `quarter`, `strip`) выглядят аккуратно.
- `unmount` снимает подписки и останавливает таймеры и звук (кроме как во время сессии).
- Никакой сети, аналитики и трекеров.
