# Формат файла `.melete` (обмен с командой)

Файл для отправки песен и сет-листов участникам команды: репетиции, служения. Без серверов: файл уходит через
«Поделиться» (Telegram, WhatsApp, почта) и открывается в Melete — кнопкой «Принять файл .melete» в «Песнях»
или открытием файла на Android. Код: `src/core/share.js` (формат), `src/core/screens/share.js` (экраны),
`android/.../SharePlugin.java` (отправка и приём на Android). Тесты: `tests/share.test.js`.

## Устройство

Zip-архив:

- `melete.json` — описание (UTF-8 JSON);
- `files/<n>-<имя>` — табы, ноты и (по выбору) записи.

```json
{
  "format": "melete",
  "v": 1,
  "created": 1792000000000,
  "title": "Репетиция",
  "songs": [
    { "ref": "lx3k…", "title": "…", "artist": "…", "genre": "…", "key": "Am", "targetBpm": 72,
      "notes": "[Припев]\nAm  F  C  G\n…", "capo": 3, "metro": { "bpm": 72, "num": 6, "den": 8 } }
  ],
  "set": { "ref": "e…", "title": "…", "kind": "rehearsal", "start": 0, "end": 0, "allDay": false,
           "place": "…", "note": "…", "songs": ["lx3k…"] },
  "files": [
    { "ref": "…", "path": "files/1-Song.musicxml", "name": "Song.musicxml", "type": "…", "kind": "tab",
      "fmt": "score", "size": 1234, "songs": ["lx3k…"] }
  ]
}
```

- `ref` — id песни у отправителя (или `from`, если песня сама была получена): по нему повторно присланная песня
  обновляется, а не дублируется. Если `ref` не совпал — сравнение по названию и исполнителю (без учёта регистра, «ё» = «е»).
- Поля песни, которых нет, не отправляются. **Личное не отправляется:** выученность, сложность, текущий темп,
  категория и метки, время и записи занятий.
- `set` — событие календаря (сет-лист): порядок песен — `songs`. Повторяющееся событие уходит одним повторением.
- `kind` файла: `tab` — табы и ноты (медиатека «Ноты и табы»), иначе — запись (медиатека).

## Простой JSON (без zip) — от нейросети или вручную

`melete.json` принимается и сам по себе (файл `*.melete.json` или `*.json`). Кроме песен в нём могут быть:

- `quotes` — сборники цитат (`{ title, items: [{ text, by?, src? }] }`, массив или один объект) → свои наборы
  в «Словах Мелеты» (тот же `title` — заменяется);
- `profile` — `name`, `instruments`, `level`, `days` (7 × 0/1), `goalMin` (30–3000).

**Часы, занятия, опыт до приложения, выученность, лига** через файл не меняются никогда: такие поля
отбрасываются при чтении (`cleanProfile`, `cleanSong` в `src/core/share.js`), опыт до приложения сохраняется прежним.
Полная инструкция для нейросети — `docs/ai-format.md` (она же в приложении: Профиль → «Инструкция для нейросети»).

## Приём

- Для каждой песни: «Добавить» / «Обновить» (совпавшую: меняются только поля из файла) / «Копией» / «Пропустить».
- Файлы с тем же именем и размером не дублируются — только привязываются к песне.
- Сет-лист — в календарь (по желанию); полученное раньше событие обновляется.

## Версии

`v` растёт только при несовместимых изменениях. Более новую версию приложение не открывает и просит обновиться;
новые необязательные поля добавляются без смены `v` — старые версии их пропускают.
