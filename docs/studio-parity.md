# Студия: сверка с FL Studio Mobile и n-Track Studio

Образцы — FL Studio Mobile (форма: плейлист, клипы, редакторы) и n-Track Studio (многодорожечная запись, микшер).
Функции переносятся в рамках философии приложения: вся поверхность — рабочая, управление — одной полосой,
жесты — как принято в телефонах, стабильность важнее новой функции. Обновляется по мере работы (2026-10).

Обозначения: ✓ — есть; ◐ — есть частично (чем отличается); ✗ — нет (план или почему не делаем).
