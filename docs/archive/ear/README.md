## Упражнения
`iv` — интервалы, `ch` — аккорды, `sc` — гаммы и лады, `dg` — ступени в тональности, `nt` — абсолютный слух
(ноты, набор растёт по мере успехов), `dc` — диктант (сыграть услышанную мелодию на клавишах), `pt` — пение нот
(микрофон, допуск в центах).

Уровни (`easy`, `mid`, `hard`, `custom`) задают набор вариантов: см. `LEVELS` в `music-ear.js`.
Например, аккорды на лёгком — только мажор и минор; интервалы на лёгком — м3, б3, ч4, ч5, октава.

## Данные пользователя (не удалены — вернутся вместе с модулем)
- **Статистика** — общие данные, попадают в резервную копию: `practice.v1` → `settings.ear`
  - `stats[упражнение][вариант] = { c: верных, t: всего }`
  - `days["ГГГГ-ММ-ДД"] = { c, t }` — ответы по дням (для цели на день и серии)
- **Настройки** — на устройстве: `practice.v1.tools` → `ear`
  (`sec`, `level`, `dir`, `arp`, `auto`, `mode`, `rng`, `oct`, `ref`, `goal`, `ntMode`, `ntLvl`, `ntSet`, `ntHist`,
  `ntRange`, `ntTimbre`, `ntMask`, `ntColors`, свои наборы `sets[упражнение]`). Значения по умолчанию — `normalizeEar`.
- Время, проведённое в тренажёре вне сессии, уже лежит в статистике как сессии `type: 'tool', tool: 'ear'`
  и показывается в «Статистике» под названием «Слух».

## Что нашлось при проверке на телефоне (05.10.2026)
1. **«Аккорды»: после ответа нельзя идти дальше.** Если после верного ответа нажать вариант, чтобы сравнить на слух,
   отменялся автопереход, а кнопки «Дальше» не было. Исправлено перед архивацией: «Дальше» видна всегда после ответа.
2. **«Ноты»: клавиатура выглядит странно** — клавиши вне набора серые и полупрозрачные.
3. **«Ноты»: в лёгком режиме нельзя понажимать клавиши и послушать, прежде чем ответить.**
4. Варианты на два ответа (мажор/минор) растягиваются на весь экран.

## Пожелания автора к переделке
- **Полностью настраиваемый модуль**: сложность и вообще всё — свои наборы аккордов, интервалов, гамм, ступеней, нот;
  диапазон, тембры, направление, темп звучания.
- В «Нотах» — нормальная клавиатура и режим «послушать клавиши до ответа» (как минимум на лёгком).
- Переосмыслить модуль целиком, а не только чинить: что видно на главном экране тренажёра, как устроены упражнения.

## Как вернуть
```
git mv docs/archive/ear/module src/modules/ear
git mv docs/archive/ear/music-ear.js src/music/ear.js
git mv docs/archive/ear/ear.test.js tests/ear.test.js
```
Реестр модулей подключит папку сам. Затем: вернуть словари модуля в проверку переводов (`tests/modules.test.js`),
`ear` в список встроенных (`tests/registry.test.js`) и при желании в быстрый доступ по умолчанию
(`QUICK_DEF` в `src/core/screens/home.js`); значок шины «Теория и слух» в микшере (`src/core/screens/mixer.js`).
