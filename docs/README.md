# Документы проекта

В корне репозитория:
- `README.md` — что такое Melete и что умеет; как собрать.
- `CLAUDE.md` — устройство проекта, стек, правила работы (читается в начале каждой сессии Claude Code).
- `MODULE_SPEC.md` — контракт модуля-инструмента и всё, что ядро даёт модулю (`ctx`).
- `ROADMAP.md` — этапы и статус (сверен с кодом).
- `DECISIONS.md` — решения автора, новые сверху своего месяца; внизу — нерешённые вопросы.
- `LICENSE` — GPL-3.0; `LICENSES.md` — сторонние компоненты и их лицензии.

Здесь, в `docs/`:
- `next-2026-10.md` — пожелания автора за октябрь 2026: что сделано, что осталось.
- `share-format.md` — формат файла `.melete` (песни, табы, сет-листы для команды).
- `ai-format.md` (`.en.md`, `.uz.md`) — инструкция для нейросети: как собрать файл со своими данными для загрузки.
- `quotes.md` — правила наборов слов маскота (источники, проверка фактов).
- `research-2026-10.md` — исследование конкурентов и предложения (на рассмотрении автора).
- `online.md` — черновик об онлайн-учёте и синхронизации (отложено).
- `module-template/` — шаблон своего модуля; `mascot/` — эскизы маскота.
