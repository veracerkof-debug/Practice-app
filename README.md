# Melete

**Μελέτη** (греч. «упражнение, усердное занятие», 1 Тим 4:15) — приложение-компаньон в практике музыканта:
учёт занятий и набор инструментов в одном месте. Без рекламы, подписок, аккаунтов и сбора данных — всё хранится
на устройстве. Ритм недельный, без давления ежедневными сериями. Открытый код, GPL-3.0.

## Что умеет

**Практика**
- Занятия (сессии): свободные и по песне; инструменты открываются окнами прямо в занятии, время идёт само
  и не сбивается при погасшем экране. Помодоро и секундомер «сколько я играю».
- Неделя и цель: дни практики, кольцо цели, статистика по дням, неделям, песням, жанрам и меткам.
- Лиги: самоцвет растёт от часов практики в приложении. Часы «до приложения» в лигу не идут.
- Маскот Мелетий (или Мелета, или без маскота): одна фраза дня на главной и напоминания о практике.

**Песни, календарь, команда**
- Библиотека песен: категории, жанры, метки, выученность, темп, текст с аккордами, табы, ноты и записи к песне.
- Календарь: репетиции, уроки, концерты, дедлайны и цели; повторы; выгрузка `.ics`.
- Команда: песни, табы и сет-листы — одним файлом `.melete` через «Поделиться», без серверов.
- Церковный режим: Библия (Синодальный перевод, 66 книг), планы чтения (готовые и свои), импорт песен
  из ProPresenter, EasyWorship, OpenLyrics, PowerPoint и Holyrics.

**Инструменты**
- Метроном, тюнер, пианино (синтезатор с пресетами), пэды и дрон, теория (квинтовый круг, гаммы, аккорды, гриф).
- Глайдер — бесладовая клавиатура: высота по горизонтали, эффекты по вертикали.
- Терменвокс — игра руками перед камерой (соло, аккорды, гитара); камера обрабатывается только на устройстве.
- Медиатека (замедление без смены высоты, A–B, метки, видео), табы и ноты (Guitar Pro, MusicXML, PDF), текст с аккордами.
- Диктофон с обработкой вживую и после записи; спектр и шумомер.
- Запись в инструментах: звук, видео или MIDI (сама игра: пианино — ноты и педаль, глайдер и терменвокс — скольжение
  по MPE); файл `.mid`; MIDI-клавиатура по USB и Bluetooth.

**Данные**
- Папка Melete на телефоне: данные, записи, табы, PDF и тексты лежат по полочкам и синхронизируются в обе стороны;
  резервные копии с подписью (кто и когда), автокопия раз в день.
- Языки: русский, oʻzbekcha (латиница), English. Оформление: классика и «Минимал», темы, палитры и свои цвета.

**Демонстрация** — [veracerkof-debug.github.io/Practice-app/show](https://veracerkof-debug.github.io/Practice-app/show/): без регистрации, сразу с выдуманным
музыкантом — песни с аккордами, табы и ноты, записи и видео, календарь и почти два года занятий в статистике. Всё выдумано
и хранится отдельно от настоящих данных веб-версии; можно трогать что угодно.

Обе обновляются сами при каждом изменении в репозитории. Разработку видно по истории коммитов, решения — в `DECISIONS.md`.

## Платформы
Android (APK; позже Google Play и F-Droid), веб, Windows (установщик в релизе «pre»).

## Разработка
```
npm install        # зависимости
npm run dev        # сервер разработки (с телефона по Wi-Fi: http://<IP компьютера>:5173)
npm test           # тесты (Vitest)
npm run build      # сборка в dist/
npx cap sync android
```
Устройство проекта, правила и стек — `CLAUDE.md`; контракт модуля-инструмента — `MODULE_SPEC.md`;
решения автора — `DECISIONS.md`; план — `ROADMAP.md`; форматы файлов и прочее — папка `docs/`.

## Лицензия
