# Practice (рабочее название)

Приложение для практики музыкантов: веди учёт занятий и держи все нужные инструменты под рукой.
Без рекламы, подписок и слежки. Открытый код.

## Что умеет
**Ядро**
- Сессии практики: свободная и по конкретной песне; таймер, который не сбивается при выключенном экране.
- Недельный ритм вместо давящих ежедневных серий: цель на неделю, дни практики и отдыха.
- Статистика: время по дням и неделям, карта практики, рост темпа по песням, разбивка по жанрам и меткам.
- Ударный режим по неделям, кольцо цели с перевыполнением.
- Библиотека песен: категории, жанры с цветами, теги, выученность, темп, заметки, аккорды и тексты.
- Окна в сессии: до четырёх инструментов одновременно, раскладка запоминается для каждой песни.
- Боковая шторка-микшер: громкость каждого инструмента из любого места.
- Языки: русский, oʻzbekcha, English. Темы: светлая, тёмная, «Бумага», OLED, акцентные цвета.

**Модули**
- Метроном с колесом темпа, акцентами, дроблением, тренером ускорения и тихими тактами.
- Тюнер: чистый вид, строи и свои строи, точность, гриф-подсказка для новичков, 4 вида отображения.
- Пианино: пресеты звука, пульт синтезатора, Hold, два ряда.
- Пэды и дрон: 6 тембров, созвучия, слои, плавные переходы, пресеты.
- Теория: квинтовый круг, гаммы, аккорды, интервалы — на грифе и клавишах.
- Тренажёр слуха: интервалы, аккорды, гаммы и лады, ступени, абсолютный слух, диктант, пение нот.
- Помодоро, медиатека (замедление, A–B, волна, винил), табулатуры Guitar Pro / MusicXML.
