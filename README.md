# Melete · Μελέτη

Приложение для практики музыкантов: учёт занятий и все нужные инструменты под рукой.
Без рекламы, подписок и слежки; данные — только на устройстве. Открытый код.

Название — от греческого μελέτη, «упражнение, усердное занятие».

## Что умеет
**Ядро**
- Занятия: свободные и по песне; таймер не сбивается при выключенном экране, на Android работает в фоне.
- Недельный ритм вместо давящих ежедневных серий: цель на неделю, дни практики и отдыха.
- Статистика: время по дням и неделям, карта практики, рост темпа по песням, жанры и метки.
  Лиги — самоцвет по часам практики (от камня до обсидиана); званий нет.
- Библиотека песен: категории, жанры, теги, выученность, темп, тональность, заметки, текст с аккордами;
  поиск песни в MusicBrainz, темп и тональность по записи; импорт песен (PowerPoint, ProPresenter, EasyWorship, Holyrics).
- Календарь: месяц, неделя, список; репетиции, дедлайны, цели, повторы, экспорт `.ics`.
- Команда: песни, табы, ноты и сет-листы — одним файлом `.melete` через «Поделиться».
- Окна в сессии: до четырёх инструментов одновременно, раскладка запоминается для каждой песни.
- Запись в инструментах: звук приложения и микрофон, видео, MIDI (файлы `.mid`).
- Напоминания о практике без серверов; маскот на выбор — Мелетий или Мелета (или без маскота).
- Папка Melete на устройстве, резервные копии с автокопией раз в день, демо-набор.
- Церковный режим: Библия (Синодальный перевод, модули MyBible, планы чтения), стихи разделов.
- Языки: русский, oʻzbekcha, English (и греческий — в оформлении «Минимал»).
  Темы: системная, светлая, тёмная, «Бумага», OLED; палитры и свой цвет; размер интерфейса.

**Инструменты** (каждый — модуль, включается и выключается)
- Метроном: колесо темпа, акценты, дробление, тренер ускорения, тихие такты.
- Тюнер: строи и свои строи, стробоскоп, режим новичка с грифом.
- Пианино и синтезатор: пресеты, пульт звука, Hold, два ряда, MIDI-клавиатура.
- Дрон и пэды: тембры, созвучия, слои, плавные переходы, звуки для поклонения.
- Глайдер: бесладовая клавиатура с эффектами и привязкой к нотам.
- Терменвокс: игра руками перед камерой (распознавание на устройстве).
- Теория: квинтовый круг, гаммы и лады, аккорды, интервалы, определитель аккорда и гаммы.
- Помодоро и секундомер.
- Медиатека: аудио и видео, замедление, повтор A–B, тайм-коды, волна и винил.
- Табы, ноты и текст: Guitar Pro / MusicXML, PDF, текст с аккордами и транспонированием.
- Диктофон: обработка вживую и после записи, эквалайзер, входы USB и Bluetooth.
- Спектр и шумомер.

Тренажёр слуха отложен и вернётся в переделанном виде (`docs/archive/ear/`).

## Разработка
```
npm install       # зависимости
npm run dev       # сервер разработки (доступен с телефона по Wi-Fi)
npm test          # тесты (Vitest)
npm run build     # сборка в dist/
```
Устройство проекта и правила — `CLAUDE.md`, контракт модуля — `MODULE_SPEC.md`, решения — `DECISIONS.md`,
план — `ROADMAP.md`. Предрелизный APK собирает GitHub Actions при каждом пуше (релиз «pre»).
