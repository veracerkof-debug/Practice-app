## Третий этап продукта (черновик автора, октябрь 2026): студия-черновик и лупер
Цель — набросать песню прямо в приложении: 2–3 аккорда, бас, пэд, струнные. Очень урезанная «FL Studio»,
но работает из коробки и не пугает. Опора — то, что уже есть: синтезатор и его звуки, пэды, планировщик
метронома, запись MIDI и файлы .mid (`src/core/midi.js`, `src/music/midi.js`).
- [x] Проект песни: темп, размер, тональность; привязка к песне библиотеки (песня сессии)
- [x] Дорожки: инструмент (пианино, пэд, бас, синт, струнные — звуки приложения), название, цвет, громкость, тишина и соло
- [x] Пиано-ролл: ноты сеткой, длительность, перемещение пальцем, привязка к сетке; проигрывание по кругу
- [x] Аккордовая дорожка: аккорд на такт (выбор из тональности), режимы — держать, ритм, арпеджио (вверх, вниз, туда-обратно; длительность ноты)
- [x] Ноты: экспорт MusicXML — партии дорожек открываются в «Табах и нотах» (alphaTab) и в нотных программах; .mid — в медиатеку. Ввод табулатуры цифрами — не делаем: ноты и аккорды покрывают черновик
- [x] Лупер — отдельный инструмент: запись с микрофона по счёту метронома, наложения (overdub), отмена последнего слоя, несколько петель, громкость слоёв, сохранение в медиатеку; крупные кнопки и педаль Bluetooth (клавиши)
- [x] Лупер в студии: дорожка-петля — запись из медиатеки (сведение лупера) по кругу с первого такта, рядом с дорожками нот
- [x] Студия — своя вкладка внизу, экран по форме FL Studio: рэк каналов (барабаны — свои каналы), плейлист лентой
- [x] По образцу FL Studio: паттерны и плейлист (песня), переключатель «паттерн | песня», степ-секвенсор ударных, клавиши в пиано-ролле, свинг, отмена
- [x] Чтение табов: формат по содержимому (gp3–8, gpx, MusicXML/.mxl, Capella, PDF), текстовые табы (ASCII) с воспроизведением и вставкой текстом, ударные из DAW нотами
- [x] Обмен со студиями: «Для DAW» — мультитрек .mid (ударные на 10-м канале, GM-инструменты, темп, размер, тональность); чтение .mid, Ableton .als, Reaper .rpp, FL Studio .flp → ноты в «Табах» (раздел «MIDI и DAW») и «В студию»
- [x] Стабильность прежде всего: проекты сохраняются после каждого действия, проигрывание с опережением планировщика (как метроном); проверить на слабом телефоне
